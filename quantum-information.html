Quantum information

Quantum error correction as an organizing principle for spacetime — and the entanglement structures, codes, and operator algebras that make it work.

The area

The observation that the bulk-to-boundary map in AdS/CFT behaves like a quantum error-correcting code reframed a set of puzzles about subregion duality: bulk operators are recoverable from boundary subregions in a way that mirrors the recovery of logical information from a code subspace. Toy models — tensor network codes with holographic geometry — make this concrete enough to compute with.

I'm interested in what happens when those models are pushed away from their idealized settings: irregular or fractal boundary structure, non-uniform erasure patterns, and states whose entanglement comes from topological order rather than geometry. The recurring question is which code-theoretic properties are robust features of holography and which are artifacts of a convenient construction.

Questions I'm interested in

  • How do holographic codes behave under structured erasure? Fractal-like boundary erasures probe threshold behaviour in a regime that uniform random erasure models don't capture.
  • What does the boundary's geometry do to code properties? Self-similar and irregular boundaries change reconstruction wedges in ways that have code-theoretic consequences.
  • Do topologically ordered states satisfy holographic entropy inequalities? Topological entanglement entropy provides a family of states with sharp entropy signatures to test against.
  • Can gauge theory be reformulated in error-correction terms? Confinement and deconfinement have a natural reading as a question about correctability, which brings operator-algebraic tools — type III factors, subfactor indices, crossed products — into contact with the code picture.
  • What is the right algebraic notion of a code in continuum QFT? Finite-dimensional code intuition doesn't transfer cleanly when the local algebras are not type I.
